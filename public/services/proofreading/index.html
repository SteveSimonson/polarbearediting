Proofreading for the final clean pass

Professional book proofreading to catch typos, punctuation issues, and production errors after copyediting and layout freeze.

Proofreading is not a cheaper developmental edit. It is the last quality gate: residual typos, punctuation slips, repeated words, bad breaks, and “how did that survive?” glitches. The file should already be the book you mean to publish. We are hunting leftovers, not rebuilding the house.

The process

  1. Fit check. Has it been copyedited (or an equivalent high-quality pass)? Is layout frozen, or are we proofing a Word file you still plan to flow into InDesign or Vellum?
  2. Sample pages. Enough to see residual error rate. If the sample still needs language work, we will recommend stepping back a stage.
  3. Written scope. File type (Word, PDF, ebook proof), what we mark, how you receive corrections, and a delivery date.
  4. The hunt. A slow, cold read against the style sheet if you have one—typos, punctuation, numbering, obvious layout breaks.
  5. Handoff. Marked file plus a short list of queries that are not silent fixes. Then you upload.

Ideal sequence: developmental or critique → revise → copyedit → format → proof → publish. Details in types of editing and when to hire an editor.

Who it is for

Authors on the last mile: indie and hybrid writers heading for KDP or wide distribution, and anyone whose copyedit is implemented and whose pages should not move again. If you are still rewriting Chapter 12, you are not a proofreading client yet—and we will tell you that.

What you receive

  • Corrections on the near-final file (tracked changes in Word, or marks on a layout PDF, as scoped)
  • Flags for spelling, punctuation, and basic grammar misses that survived earlier passes
  • Formatting glitches: extra spaces, odd hyphens, style breakouts, bad breaks when the file is laid out
  • Obvious continuity leftovers if they surface in the final file (courtesy, not a plot edit)

When not to buy this

  • You have not had a copyedit (or you were the only copyeditor, and the pages still wobble). Skipping copyedit to “just proof” usually produces an elegant mess.
  • You are still moving scenes, changing names, or writing a new ending
  • You want structural notes, character work, or “make it flow.” That is developmental editing or a critique
  • You want us to guarantee a bestseller-clean file with zero remaining errors. No honest proofreader promises perfection—only a professional last pass

When proofreading makes sense: after copyediting, after interior formatting for print/ebook when possible, and before you hit publish—not while you are still rewriting.

Educational rates

Industry-style ballparks for proofreading typically run $0.01–$0.02 per word. Copyediting is usually $0.018–$0.035; a manuscript critique $0.008–$0.018; developmental $0.03–$0.06. Those are educational ranges, not a Polar Bear quote. FAQ

Can proofreading replace copyediting?

No. Proofreading assumes the text is already stable. Skipping copyedit to “just proof” usually produces an elegant mess.

Should I proofread before or after formatting?

After, when you can. Proofreading on laid-out pages catches bad breaks, stacked hyphens, running heads, and other production glitches a Word file will never show. If you must proof the manuscript first, budget a short post-layout check.

How much does book proofreading cost?

Educational market ranges for proofreading typically run $0.01–$0.02 per word. Copyediting is higher ($0.018–$0.035). Use the cost calculator for a ballpark, then request a scoped quote.

Will a proofreader catch plot holes?

Only if they trip over them in passing. Plot, character, and argument are developmental work. A proofreader may flag an obvious leftover (a character who died in Chapter 8 appearing in Chapter 19), but that is courtesy, not the job you bought.

Can I proofread my own book?

You can catch some of it, especially after a cooling-off period and a read-aloud. You will not catch all of it. Familiarity is the enemy of this pass. If you can only afford one professional, do not spend it here while the story is still moving.
